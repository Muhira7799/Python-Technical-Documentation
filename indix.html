Introduction

Python is a popular programming language that is easy to learn and use.

It is commonly used for web development, data analysis, automation, and artificial intelligence.

print("Hello, World!")

Python uses simple and readable syntax.

  • Easy to learn
  • Easy to read
Variables

Variables are used to store data in a Python program.

You can create a variable by assigning a value to a name.

name = "Muhira"

Python automatically determines the type of the value stored in a variable.

  • Variables store information.
  • Variable names should be meaningful.
Data Types

Python has several built-in data types.

Some common data types are strings, integers, floats, and booleans.

age = 23 student = True

Lists can also be used to store multiple values.

  • String
  • Integer
  • Float
  • Boolean
Conditional Statements

Conditional statements allow a program to make decisions.

The most common conditional statement in Python is the if statement.

if age >= 18:

You can use else when the condition is not true.

else:
  • if checks a condition.
  • else runs when the condition is false.
Loops

Loops are used to repeat a block of code.

Python provides for loops and while loops.

for number in numbers:

A for loop is useful when you want to go through a collection of items.

while count < 5:

A while loop continues running while its condition is true.

  • For loops repeat over a sequence.
  • While loops repeat while a condition is true.
