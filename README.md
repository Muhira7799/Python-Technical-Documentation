#  Technical Documentation Page

This project is a Technical Documentation Page about **Python**. I created it as part of my learning journey with **freeCodeCamp** to practice HTML and CSS.

##  About the Project

The page provides basic information about Python, including:

* Introduction
* Variables
* Data Types
* Conditional Statements
* Loops

It also includes a navigation bar that allows users to quickly move between the different sections.

##  Technologies Used

* HTML5
* CSS3
* CSS Media Queries

##  What I Learned

While working on this project, I practiced:

* Creating a semantic HTML structure
* Using `main`, `section`, `nav`, and `header`
* Creating navigation links with anchor tags
* Using `id` attributes to link different sections
* Styling a fixed navigation bar
* Using CSS for page layout
* Creating responsive designs with `@media`

##  Responsive Design

I used a CSS media query to make the documentation page responsive on smaller screens.

On smaller devices, the navigation changes from a fixed sidebar to a full-width navigation section.

##  Purpose

The main purpose of this project was to improve my understanding of **HTML structure, CSS styling, navigation, and responsive web design**.
